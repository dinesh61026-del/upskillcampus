# Smart Irrigation System

## Industrial Internship Project

This project was developed as the final project for the
Free Summer Internship in Embedded and IoT – 2026
through Upskill Campus.

## Project Description

The Smart Irrigation System is an ESP32-based embedded
system designed to demonstrate automatic irrigation based
on soil moisture conditions.

The ESP32 monitors the soil moisture value and compares it
with a predefined threshold. When the soil is dry, the relay
is activated to represent the water pump. When the soil is
wet, the relay is switched OFF.

An OLED display is used to show the soil value, soil
condition and pump status.
